# Email Inbox Simulator 📬

A Python OOP project simulating a basic email system with users, 
inbox management, and email state tracking.

## What it does
- Users can send emails to each other
- Inbox supports listing, reading, and deleting emails
- Emails track read/unread status and timestamp automatically
- Input validation prevents invalid inbox operations

## Concepts
OOP, multiple classes, class relationships, `datetime`, 
`__str__`, instance state, type hints
